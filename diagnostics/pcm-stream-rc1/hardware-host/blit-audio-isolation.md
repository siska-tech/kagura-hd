# BLIT STORM時のPCM不連続の切り分け

2026-11-08。FPGAは既存の+0.090 ns画像、SHA-256 `DE71D3FB2F45F2F119413659EF199AD72569BD8A74C6C1B68AD5AE44F119CBCB`。FPGA RTL、SDC、bitstreamを変更せず、Hostだけに記録を追加した。各区間25秒、PCMパターンとSRAM投入手順は同じ。音声のみをUGREEN 15390から48 kHzステレオで記録した。各回で承認済みQueue8を復旧し、RP2040 Flashの前後一致を確認した。

|25秒条件|FILL / COPY / PALETTE / PRESENT|10 ms低RMS区間 左 / 右|マーカー不一致 左 / 右|
|---|---:|---:|---:|
|`t` BLIT STORM|16950 / 16343 / 4 / 587|11 / 10|241 / 242|
|`p` 初期画像のページをPRESENTのみで交互表示|0 / 0 / 0 / 587|7 / 8|224 / 223|
|`h` 描画は非表示面、PRESENTは表示面に固定|16951 / 16344 / 4 / 587|11 / 10|241 / 243|
|`n` 初期画面固定、描画コマンドなし|0 / 0 / 0 / 0|6 / 6|287 / 265|
|`k` 同じ初期画面・表示面を黒パレットで走査|0 / 0 / 0 / 0|0 / 0|0 / 0|
|`n` 元の配色で再試験、`k`と同じHost ELF|0 / 0 / 0 / 0|8 / 8|209 / 217|

低RMSはデコード音声を10 msごとに分け、RMSが20/32768未満の区間。開始・停止付近は除いた。マーカー比較は各291半面。波形位相が急変する区間では位相追跡がずれるため、マーカー不一致数は失われた半面数を表さない。黒では通常の共通位相差20サンプル・16.57 ppmに戻った。元配色の再試験では20 msの低RMS区間が4箇所、左右同時に再現した。

波形とHostトレースは音声開始点を基準におおよそ合わせた。イベント近傍のコマンドは±15 msの範囲で記録し、個別コマンドとの因果は判定しない。次の直接確認は元配色と黒の25秒を同じ機器構成で撮り、受信前のHDMIパケット列とデコード後の音声を比較すること。メガデモと採用判定は保留。

## 書込み経路とFPGA画像の対照

元の配色の固定画面で、従来PCM2の固定2半面ループを候補→元RC1→候補の順に実行した。3回とも低RMS区間0、291半面のマーカーは全件一致した。この固定ループと同じPCM波形を使い、書込みの条件を1段ずつ変えた。

|25秒条件|+0.090 ns版 低RMS 左 / 右|元RC1 低RMS 左 / 右|
|---|---:|---:|
|`c` 従来PCM2のみ|0 / 0|0 / 0|
|`u` 同じ波形でストリーム補充|6 / 6|対象外|
|`v` ストリームを有効にして元の半面を再公開、データ書込みなし|0 / 0|対象外|
|`w` 従来PCM2＋別のPSRAM領域へのWRITE|6 / 6|0 / 0|
|`x` 従来PCM2＋QSPI窓へのPCMパターン書込み、PSRAM命令なし|10 / 8、再試験10 / 10|0 / 0|
|`z` 従来PCM2＋QSPI窓へのゼロ書込み、PSRAM命令なし|0 / 0|未実施|

`w`、`x`、`z` は各292バッチ、1バッチ128×64 byteで補充と同量。`x` と `z` は5 MHz、1チャンク237 µsのペーシング、1バッチ最大30,352 µsで一致。最後の `z` →元RC1 `x` →候補 `x` は同一Host ELFで比較した。候補 `x` の再試験も正常終了し、FPGAの観測フラグは各回E1=0、PCM異常なし、タイムアウト0だった。 `c` の別試行で録音の立ち上がりが片chで1サンプル先行し、位相推定を周期末尾に置くと誤不一致になった。解析で初期位相を最も近い符号付き値に直し、以後同じ手順を使った。

ストリーム所有権処理とPSRAM WRITE命令の両方を外しても、候補の非ゼロQSPI窓書込みで再現した。送る値をゼロにした候補と、同じ非ゼロデータを送った元RC1では再現しなかった。今回の再現条件は候補画像、元の配色、データが切り替わるQSPI窓転送の組合せ。QSPIパッド、FPGA内部の窓RAM・配線の切り替わり、電源・TMDSリンクのどこが最初に乱れるかは未特定。内部HDMI FIFOは観測上正常で、外部HDMIパケットエラーは未計測。次の確認は `x` と `z` でQSPIとHDMIを同期観測するか、別の受信器で同じ対照を取ること。

証跡は `build/pcm-stream-rc1/legacy-color-*`、`stream-match-*`、`stream-traffic-*`。全回でSRAM限定投入、承認済みQueue8への復旧とRP2040 Flashの前後一致を確認した。FPGA RTLと両画像の変更はない。メガデモおよび採用は引き続き保留。
