# 出典・ライセンス

FOUR OPERATORS は、このリポジトリと同じ Apache-2.0 で提供します。新規に作成したものは次のとおりです。

- C、Python、シェル、PowerShell のコード
- FM 音源エンジンと音色
- 曲（A マイナー、120 BPM、65 小節）
- 5×7 ドットのフォント（`src/font.c`）
- 映像効果

既存の作品の曲、画像、ロゴ、フォントは使っていません。

既存の実装は、次のものをそのまま使っています。出典は、それぞれのディレクトリに書かれているとおりです。

- KAGURA C SDK（`software/kagura_fb/`）
- RP2040 の PIO QSPI ホスト（`software/beyond16/src/b16_qspi.c`、`software/midnight_terminal/vendor/kagura_host.pio`）
- Pico SDK と TinyUSB

Pico SDK と TinyUSB のライセンスは、[MIDNIGHT TERMINAL の vendor](../midnight_terminal/vendor/) を参照してください。
