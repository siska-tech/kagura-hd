# ライセンスと出典

本デモのC/Pythonコードはプロジェクトと同じApache-2.0。ロゴの色付け・額縁・球・幾何学素材・窓・plasma・BGMと効果音は`tools/generate.py`で制作したオリジナルで、他作品のスクリーンショットやロゴは使用していない。

文字の基礎字形は既存KAGURAプロジェクトの美咲ASCII rows。Copyright (C) 2002-2021 Num Kadoma。使用・複製・改変・商用/非商用配布の許諾は[既存font-license.txt](../kagura_fb/showcase/vendor/font-license.txt)、元同梱文は[misaki.txt](../midnight_terminal/vendor/misaki.txt)を参照。フォントそのものを新規オリジナルと称さない。

KAGURA C SDK、PIO、可逆LZ codecは既存リポジトリ実装を再利用。PIOの由来は[前作のprovenance](../midnight_terminal/vendor/qspi-provenance.json)。Pico SDK/TinyUSBのライセンスは[前作vendor](../midnight_terminal/vendor/)。依存ツールのバイナリを本デモの配布ソースへ複製していない。
